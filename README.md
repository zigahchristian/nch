# New Catholic Hymnal

New Catholic Hymnal 2021 – The New Catholic Hymnal is a digital compilation of updated traditional Catholic hymns, created to inspire and guide you in singing, worship, and prayer throughout the Catholic Mass.

This project is a starting point by Christian & Joshua - 2025.
